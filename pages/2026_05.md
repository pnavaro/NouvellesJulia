## Packages


- [Arborist.jl](https://github.com/CodeReclaimers/Arborist.jl) Generic genetic programming for Julia.
- [ArnoldiVandermonde.jl](https://github.com/complexvariables/ArnoldiVandermonde.jl) constructing and working with Arnoldi-based Vandermonde matrices. 
- [BayesKNN.jl](https://github.com/stanlazic/BayesKNN.jl) Probabilistic (Bayesian) K-Nearest Neighbours.
- [DataSplits.jl](https://github.com/davide-grheco/DataSplits.jl) A Julia package implementing several data splitting algorithms.
- [DependencyAtlas.jl](https://codeberg.org/karei/DependencyAtlas.jl.git) Turn Julia code into a graph you can actually explore.
- [FactorGraph.jl](https://github.com/mcosovic/FactorGraph.jl) inference over the factor graph with continuous or discrete random variables using the belief propagation algorithm.
- [FFTLoggin.jl](https://github.com/binado/FFTLoggin.jl) vectorized FFTLog implementation for fast Hankel transforms.
- [HexMeshes.jl](https://github.com/eschnett/HexMeshes.jl) Conforming hexahedral meshes in in 1, 2, and 3 dimensions.
- [HydroElasticFEM.jl](https://github.com/CMOE-TUDelft/HydroElasticFEM.jl)  finite element (FE) simulation of hydro-elastic wave–structure interaction problems. 
- [LAlatex.jl](https://github.com/ea42gh/LAlatex.jl) convert julia objects to latex representations, render in jupyter notebooks. Focus on Linear Algebra matrices, etc
- [ManifoldMakie.jl](https://github.com/JuliaManifolds/ManifoldMakie.jl) Makie recipes to plot data on manifolds!
- [MetidaFlows.jl](https://github.com/PharmCat/MetidaFlows.jl) A lightweight workflow engine for scientific and analytical pipelines in Julia.
- [MoleculeHub](https://github.com/MoleculeHub) A collection of cheminformatics tools written in Julia. 
- [Nbody2D.jl](https://github.com/jfeldbrugge/Nbody2D.jl) particle mesh code for cosmological N-body simulations.
- [Neptune.jl](https://github.com/compleathorseplayer/Neptune.jl) Non-reactive Julia notebook — a fork of Pluto.jl where cells only run when you ask them to.
- [PDBTools.jl](https://github.com/m3g/PDBTools.jl) Read, write and manipulate atomic systems in PDB and mmCIF formats.
- [PrismMaterialDecomposition.jl](https://github.com/fdekerme/PrismMaterialDecomposition.jl) Julia framework for real-time, edge-preserving, regularized material decomposition of planar dual-energy kV projections.
- [QRecoupling.jl](https://github.com/sethkasante/QRecoupling.jl) Efficient evaluation of quantum recoupling symbols, q-hypergeometric series via cyclotomic factorization.
- [SchroedingerEquation.jl](https://github.com/physarief78/SchroedingerEquation.jl) A high-performance, polyglot solver for the 1D Schrödinger Equation. 
- [StaticDictTrees.jl](https://github.com/gcalderone/StaticDictTrees.jl) Types for tree-like data structures.
- [StochParticles.jl](https://github.com/VANvonZHANG/StochParticles.jl) SciML-native framework for particle-resolved Monte Carlo simulation.
- [TimerOutputComparisons.jl](https://github.com/johnomotani/TimerOutputComparisons.jl) Compare TimerOutput objects.
