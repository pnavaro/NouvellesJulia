## Packages

- [AlgebraicGeometricModeling](https://github.com/AlgebraicGeometricModeling) : Paquets de calcul algébrique et de modélisation géométrique.
- [AstroNbodySim.jl](https://github.com/JuliaAstroSim/AstroNbodySim.jl) : Code Julia de simulation gravitationnelle à N corps, avec unités et différentiable.
- [Chairmarks.jl](https://github.com/LilithHafner/Chairmarks.jl) : Mesure les performances des centaines de fois plus vite que BenchmarkTools, sans compromettre la précision.
- [DifferentiationInterface.jl](https://github.com/gdalle/DifferentiationInterface.jl) : Interface pour différents moteurs de différentiation automatique.
- [ExaModels.jl](https://github.com/exanauts/ExaModels.jl) : Outil de modélisation algébrique et de différentiation automatique, spécialisé dans l'abstraction SIMD des programmes non linéaires.
- [FastLapackInterface.jl](https://github.com/DynareJulia/FastLapackInterface.jl) : Sépare l'allocation de l'espace de travail de l'exécution pour certains algorithmes LAPACK.
- [EcologicalNetworksDynamics.jl](https://github.com/BecksLab/EcologicalNetworksDynamics.jl) : Simulateur de dynamiques écologiques.
- [FFTIndexing.jl](https://github.com/brainandforce/FFTIndexing.jl) : Objets d'indexation pour manipuler des transformées de Fourier.
- [IncrementalSVD.jl](https://github.com/JuliaLinearAlgebra/IncrementalSVD.jl) : Calcule progressivement une décomposition en valeurs singulières tronquée approximative.
- [MadNLP.jl](https://github.com/MadNLP/MadNLP.jl) : Solveur de programmation non linéaire.
- [MultiPrecisionArrays.jl](https://github.com/ctkelley/MultiPrecisionArrays.jl) : Fournit des structures de données et des solveurs pour plusieurs variantes de l'affinage itératif.
- [PAndQ.jl](https://github.com/jakobjpeters/PAndQ.jl) : Système de calcul formel pour la logique propositionnelle.
- [ParticleDA.jl](https://github.com/Team-RADDISH/ParticleDA.jl) : Paquet d'assimilation de données par filtres particulaires.
- [REPLSmuggler.jl](https://github.com/Klafyvel/REPLSmuggler.jl) : Envoie du code à votre REPL Julia.
- [SIMDMathFunctions.jl](https://github.com/ClimFlows/SIMDMathFunctions.jl) : Fonctions mathématiques vectorisées rapides pour SIMD.jl, utilisant SLEEFPirates.jl.
- [StableDistributions.jl](https://github.com/jaksle/StableDistributions.jl) : Génération et estimation de lois stables.
- [TrixiParticles.jl](https://github.com/trixi-framework/TrixiParticles.jl) : Simulations multiphysiques fondées sur des particules.
- [WGPUCompute.jl](https://github.com/JuliaWGPU/WGPUCompute.jl) : Interface de tableaux pour WGPU.
- [WriteDocx.jl](https://github.com/PumasAI/WriteDocx.jl) : Paquet de création de fichiers DOCX pour Microsoft Word à partir de zéro.
