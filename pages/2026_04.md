## Packages

- [AeroTrixi](https://github.com/ACoM-RWTH/AeroTrixi.jl) High-fidelity Aerodynamic Simulations with Trixi.jl.
- [BatchSolve](https://github.com/mattsignorelli/BatchSolve.jl) Vectorized, batched root finders and minimizers. Also vectorized finite differences.
- [BayeredImages](https://github.com/brainandforce/BayeredImages.jl) Tools for working with raw color images from cameras that use color filter arrays.
- [BinderPlots](https://github.com/jverzani/BinderPlots.jl) A lightweight plotting package for use within resource-constrained environments like Binder.
- [Giac](https://github.com/s-celles/Giac.jl) Julia interface to the Giac computer algebra system.
- [GroupFunctions](https://github.com/davidamaro/GroupFunctions.jl) compute D-functions, which are entries of the irreducible representations of the unitary group U(d).
- [ImageTally](https://github.com/alejandromerchan/ImageTally.jl) nteractive point-and-click image counting and landmark placement for scientific images. 
- [DataLinter](https://github.com/zgornel/DataLinter) Linting tools for ML workflows, data, code.
- [LAlatex](https://github.com/ea42gh/LAlatex.jl) convert julia objects to latex representations, render in jupyter notebooks. Focus on Linear Algebra matrices.
- [ManifoldsGPU](https://github.com/JuliaManifolds/ManifoldsGPU.jl) GPU/CUDA support for JuliaManifolds.
- [MichiBoost.jl](https://github.com/pebeto/MichiBoost.jl) gradient boosting with symmetric (oblivious) decision trees and ordered target encoding for categorical features.
- [MPIDenseLUs](https://github.com/johnomotani/MPIDenseLUs.jl) Dense-matrix LU factorization and solve using distributed+shared-memory MPI.
- [MPISharedMemLUs](https://github.com/johnomotani/MPISharedMemLUs.jl) Standard (row-pivoting) and column-pivoting LU factorisation, with shared-memory MPI parallelisation.
- [NeuralEstimators](https://github.com/msainsburydale/NeuralEstimators.jl) simulation-based, likelihood-free parameter inference using neural networks.
- [OpenSourceRoutingMachine](https://github.com/moviro-hub/OpenSourceRoutingMachine.jl) high-performance routing engine for road networks. 
- [ProfilePerfetto](https://github.com/fonsp/ProfilePerfetto.jl) Super easy profiling for Julia.
- [Regions](https://github.com/schrpe/Regions.jl) defines a set of types and functions that model a discrete 2-dimensional region concept. It can be used for various purposes in machine vision and image processing. 
- [RustCall](https://github.com/AtelierArith/RustCall.jl) calling Rust code directly.
- [Therapy](https://github.com/GroupTherapyOrg/Therapy.jl) Build interactive web applications with fine-grained signals, server-side rendering, and WebAssembly islands. 
- [UniformStreamlines](https://github.com/antoniosgeme/UniformStreamlines.jl) lightweight Julia package for generating and plotting evenly spaced streamlines in 2D, 3D, and N-D vector fields using the Jobard–Lefer algorithm.
- [UpSetPlot](https://github.com/ljournot/UpSetPlot.jl) Visualization of set overlaps with UpSet plots.
