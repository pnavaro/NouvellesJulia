## Packages

- [AdditionalDistributions.jl](https://github.com/Santymax98/AdditionalDistributions.jl) Miscellaneous distributions to extend the repertoire of distributions in Julia implemented by Distributions.jl.
- [AcceleratedRPCholesky.jl](https://github.com/Moblin88/AcceleratedRPCholesky.jl) fast, near-optimal low-rank kernel matrix approximations.
- [ASDF.jl](https://github.com/JuliaAstro/ASDF.jl) Advanced Scientific Data Format.
- [Basil.jl](https://github.com/wenrongcao/Basil.jl) 2-D finite-element viscous-flow code.
- [CodeComplexity.jl](https://github.com/charleskawczynski/CodeComplexity.jl) A package for estimating code complexity.
- [CompilerCaching.jl](https://github.com/maleadt/CompilerCaching.jl) Reusable infrastructure for caching code in the Julia compiler.
- [DocumenterCodeBlocks.jl](https://github.com/fredrikekre/DocumenterCodeBlocks.jl) A Documenter.jl plugin for more flavorful code blocks.
- [DocumenterLandingPage.jl](https://github.com/csvance/DocumenterLandingPage.jl) Vitepress like landing page for Documenter.jl.
- [FastLoess.jl](https://github.com/thisisamirv/loess-project) LOESS (Locally Estimated Scatterplot Smoothing) implementation.
- [FourierTools.jl](https://github.com/bionanoimaging/FourierTools.jl) Tools for working with Fourier space.
- [GalerkinToolkit.jl](https://github.com/GalerkinToolkit/GalerkinToolkit.jl) High-performance finite element toolbox.
- [GeometricAI.jl](https://github.com/LuisCarlosOrobio/GeometricAI.jl) A geometric machine-learning library.
- [HaloArrays.jl](https://github.com/fafafrens/HaloArrays.jl) One halo-array API for serial, shared-memory, and distributed stencil & PDE codes.
- [HemiplexNumbers.jl](https://github.com/timholy/HemiplexNumbers.jl) Implementation of hemireal arithmetic for Julia.
- [HemiplexFactorizations.jl](https://github.com/timholy/HemiplexFactorizations.jl) Matrix factorizations over the hemireals.
- [InplacePermdims.jl](https://github.com/ghyatzo/InplacePermdims.jl) Permute the dimensions of two-or-more-dimensional Julia arrays in place.
- [JuliaLibWrapping.jl](https://github.com/JuliaInterop/JuliaLibWrapping.jl) Generate language-bindings for Julia-generated shared libraries.
- [JFVTool.jl](https://github.com/FiniteVolumeTransportPhenomena/JFVTool.jl) A simple finite volume tool.
- [KaimonSlate.jl](https://github.com/kahliburke/KaimonSlate.jl) A new reactive Julia notebook.
- [KernelInterpolation.jl](https://github.com/JoshuaLampert/KernelInterpolation.jl) Multivariate (generalized) scattered data interpolation with symmetric (conditionally) positive definite kernel functions in arbitrary dimension.
- [LowLevelFEM.jl](https://github.com/perebalazs/LowLevelFEM.jl) A lightweight finite element toolbox in Julia for education, research, and rapid prototyping of weak-form formulations.
- [MethodOfLines.jl](https://github.com/SciML/MethodOfLines.jl) Automatic Finite Difference PDE solving with Julia SciML.
- [MissingPatterns.jl](https://github.com/dantebertuzzi/MissingPatterns.jl) Explore missing-data patterns straight in the terminal .
- [MTKNeuralToolkit.jl](https://github.com/VRaman-Lab/MTKNeuralToolkit.jl) Building Your Own Neurons & Components.
- [MuladdMacro.jl](https://github.com/SciML/MuladdMacro.jl) Macro for converting expressions to use muladd calls and fused-multiply-add (FMA) operations for high-performance.
- [MultiFloatLinearAlgebra.jl](https://github.com/yongjunx23-del/MultiFloatLinearAlgebra.jl) Dense CPU linear algebra for Float64-based MultiFloats.jl arithmetic.
- [NDWaveletTransforms.jl](https://github.com/impact-basin/NDWaveletTransforms.jl) N-dimensional wavelet transforms.
- [Octopus.jl](https://github.com/una-auxme/Octopus.jl) Fast octree neighborhood search.
- [PseudoSpectralReactionDiffusion.jl](https://github.com/hiscocklab/PseudoSpectralReactionDiffusion.jl) Pseudo-spectral solver for reaction-diffusion PDEs.
- [QuantumKrylov.jl](https://github.com/sjp95/qkrylov) A modern matrix-free exact diagonalization and Krylov-method framework for quantum many-body physics. 
- [QuartzHDL.jl](https://github.com/org-arl/QuartzHDL.jl) Write FPGA logic in Julia.
- [ReactionDiffusion.jl](https://github.com/hiscocklab/ReactionDiffusion.jl)
- [Sirens.jl](https://github.com/eebio/Sirens.jl) hybrid and multiscale simulation environment in Julia.
- [Snapshot.jl](https://github.com/GroupTherapyOrg/Snapshot.jl) Pluto notebooks, interactive as Therapy components.
- [SpaceStation.jl](https://github.com/GroupTherapyOrg/SpaceStation.jl) Similar to JupyterHub for Jupyter, but focused on Pluto. 
- [StructEditor.jl](https://github.com/bradcarman/StructEditor.jl) An automatic editor to modify and save data defined by Julia structs.
- [Tarang.jl](https://github.com/subhk/Tarang.jl) A (pseudo-)spectral PDE solver.
- [Terrarium.jl](https://github.com/NumericalEarth/Terrarium.jl) A framework for building next-generation differentiable and GPU-accelerated land and ecosystem models .
- [TerminalScope.jl](https://github.com/ronisbr/TerminalScope.jl) An interface for Profile, SnoopCompile, and Cthulhu.
- [TuringRegressions.jl](https://github.com/jamesalster/TuringRegressions.jl) fitting linear regressions with Turing.jl.
- [VineCopulas.jl](https://github.com/Santymax98/VineCopulas.jl) Extensible C-vine, D-vine, and R-vine copula models for Julia, built on Copulas.jl.
- [VolumeRendering.jl](https://github.com/JuliaAPlavin/VolumeRendering.jl) visualizing 3D fields – scalar or vector, always fast, interactive, and extensible.
