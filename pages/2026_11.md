# Novembre 2026

Bonjour,

Au 16 novembre, Julia 1.10.13 (branche LTS) et Julia 1.13.4 sont sorties. La première bêta de Julia 1.14 est également disponible pour les tests ; elle n'est pas destinée à la production.

## Articles et billets en ligne

- [This month in Julia World - 2026-10](https://discourse.julialang.org/t/this-month-in-julia-world-2026-10/141631)
- [Cancellation in Julia 1.14](https://viralinstruction.com/posts/cancellation/) : un billet sur le nouveau mécanisme d'annulation.
- [cuNumeric.jl : Multi-GPU Array Programming](https://discourse.julialang.org/t/cunumeric-jl-multi-gpu-array-programamming/142860) : une API Julia pour programmer sur plusieurs GPU.
- [ModuleMixins.jl v0.4](https://discourse.julialang.org/t/modulemixins-jl-seamless-data-composition/142905) : une réécriture de la composition de structures et de méthodes.
- [JOSS Papers in Julia](https://joss.theoj.org/papers/in/Julia)
- [Julia 1.10.13](https://github.com/JuliaLang/julia/releases/tag/v1.10.13) et [Julia 1.13.4](https://github.com/JuliaLang/julia/releases/tag/v1.13.4) : versions de maintenance.
- [Julia 1.14.0-beta1](https://github.com/JuliaLang/julia/releases/tag/v1.14.0-beta1) : première bêta, à essayer notamment pour tester la compatibilité des paquets.
- [Manopt.jl 1.0.0 (25 nov.)](https://github.com/JuliaManifolds/Manopt.jl/releases/tag/v1.0.0) : nouvelle version majeure du package d'optimisation sur les variétés riemanniennes, avec des changements d'API incompatibles.

## Ressources pédagogiques

- [JuliaTutorial](https://github.com/PaulSoderlind/JuliaTutorial) propose des tutoriels Julia pour les étudiant·es en finance et économétrie, sous forme de notebooks Jupyter couvrant notamment les bases, les statistiques, l'algèbre matricielle et l'optimisation. Le dépôt contient aussi des vidéos de présentation.

## Packages

Voici une sélection de paquets ajoutés au registre [General](https://github.com/JuliaRegistries/General) du 1er au 16 novembre, recoupée avec les [annonces de paquets sur le forum Julia](https://discourse.julialang.org/c/package-announcements/60). Les dates renvoient à leur première entrée dans le registre ; la sélection est arrêtée au 16 novembre à 10 h 38, heure de Paris. Les annonces de versions de paquets déjà enregistrés ne sont pas comptées comme de nouvelles inscriptions.

- [MLX.jl](https://github.com/stemann/MLX.jl) ([4 nov.](https://github.com/JuliaRegistries/General/commit/66897dc1db507c742e5970253c19b782b879de44)) fournit une API Julia pour MLX.
- [H2Factory.jl](https://github.com/djukic14/H2Factory.jl) ([2 nov.](https://github.com/JuliaRegistries/General/commit/7f162f73bd153326f85407484ce1b60185f714d3)) fournit les briques nécessaires à la construction de produits matrice-vecteur rapides fondés sur des matrices hiérarchiques.
- [DedicatedThreads.jl](https://github.com/kahliburke/DedicatedThreads.jl) ([4 nov.](https://github.com/JuliaRegistries/General/commit/1410cecc8b7996f2a937e7ea28d043db36b846dd)) permet de créer à l'exécution des pools de threads indépendants.
- [OptimizationVariableInterface.jl](https://github.com/ojwoodford/OptimizationVariableInterface.jl) ([6 nov.](https://github.com/JuliaRegistries/General/commit/b19a292df0ae4e534345acddbd02acc543a99cdb)) propose une interface commune aux optimiseurs et aux représentations de variables, notamment pour les rétractions sur les variétés.
- [Zemi.jl](https://github.com/kahliburke/Zemi.jl) ([8 nov.](https://github.com/JuliaRegistries/General/commit/89d7bfd71830688b82cb2c40f1031186793682ce)) est une base de connaissances destinée aux groupes de recherche, avec recherche sémantique et espaces de projets partagés.
- [HydroTrixi.jl](https://github.com/uofs-simlab/HydroTrixi.jl) ([8 nov.](https://github.com/JuliaRegistries/General/commit/375b388998a26b99f2398f3f1bcb4b5fe29f12c0)) est un solveur spectral-éléments adaptatif pour les modèles hydrologiques, notamment l’équation de Richards.
- [FFTL.jl](https://github.com/JuliaMath/FFTL.jl) ([9 nov.](https://github.com/JuliaRegistries/General/commit/5ba7790570a7069b01adfeac89d3848f9db3e6a1), [annonce](https://discourse.julialang.org/t/ann-fftl-jl-a-pure-julia-fft-cpu-gpu-and-a-c-library-via-juliac/143062)) est une bibliothèque de transformées de Fourier écrite en Julia, pour CPU et GPU, qui prend aussi en charge la précision multiple.
- [FiniteElementMethod.jl](https://github.com/SciML/FiniteElementMethod.jl) ([12 nov.](https://github.com/JuliaRegistries/General/commit/c7d3d4df455c3933c30efa71cc5745c33d834dc2)) discrétise un `PDESystem` sur un maillage par éléments finis de Galerkin avec Ferrite, pour produire un `DAEProblem`.
- [MappyDS.jl](https://github.com/Yuu-Miino/MappyDS.jl) ([12 nov.](https://github.com/JuliaRegistries/General/commit/14f68fa8d3e922faaae9c40f14e6bbbfdc9b76ed)) construit des applications de Poincaré pour les systèmes dynamiques hybrides et en calcule les dérivées analytiques.
- [EuclideanDistanceMatrices.jl](https://github.com/baggepinnen/EuclideanDistanceMatrices.jl) ([13 nov.](https://github.com/JuliaRegistries/General/commit/256ae27635710304891ef1a2f41c16929ef662ac)) fournit des outils pour compléter, débruiter et exploiter des matrices de distances euclidiennes au carré.
- [MatchMaker.jl](https://github.com/JuliaSymbolics/MatchMaker.jl) ([13 nov.](https://github.com/JuliaRegistries/General/commit/fa75f61bf52172dcad335c27071fa4782052c5a9)) apporte un moteur rapide de filtrage par motifs pour les expressions de SymbolicUtils.
- [WebAuthn.jl](https://github.com/JuliaServices/WebAuthn.jl) ([15 nov.](https://github.com/JuliaRegistries/General/commit/d4c7fb7fbd88984ef20c8f5ab3a52206dad49e74)) vérifie les réponses d'authentification par clé d'accès (passkey) envoyées par un navigateur à un serveur Julia.
- [GWCS.jl](https://github.com/JuliaAstro/GWCS.jl) ([15 nov.](https://github.com/JuliaRegistries/General/commit/81cde9f9967123d42a6e646ad257d2c427dfe5fa)) implémente les systèmes généralisés de coordonnées célestes.
- [BlockLinearSystems.jl](https://github.com/ojwoodford/BlockLinearSystems.jl) ([15 nov.](https://github.com/JuliaRegistries/General/commit/bd6262d89c490660ecaf914c7aa6d2e88127f658)) fournit des solveurs performants pour les systèmes linéaires denses et creux à structure par blocs.
- [ROCm_Runtime](https://github.com/JuliaGPU/AMDGPU.jl) ([15 nov.](https://github.com/JuliaRegistries/General/commit/1e482802c958496c8b773d5a85665c15f41daa1a)) rejoint l'écosystème AMDGPU.jl comme paquet dédié au runtime ROCm.
- [MeromorphicLoci.jl](https://github.com/Beforerr/MeromorphicLoci.jl) ([16 nov.](https://github.com/JuliaRegistries/General/commit/a2f39dddfbe4b848ffd13f2e151b8840cc7768c1)) recherche les zéros et les pôles de fonctions méromorphes.

### Projets non encore enregistrés dans General

- [Corset.jl](https://github.com/ParadaCarleton/Corset.jl) est un linter qui vérifie en CI des règles de qualité sur le code Julia et ses inférences ([README](https://github.com/ParadaCarleton/Corset.jl/blob/main/README.md)). La version 0.3.0 a été publiée sur GitHub le 12 novembre ([release](https://github.com/ParadaCarleton/Corset.jl/releases/tag/v0.3.0)), mais le paquet n'apparaît pas encore dans General ; il est donc signalé ici plutôt que parmi les nouvelles inscriptions.
