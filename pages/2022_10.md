## Packages

- [TensorOperations.jl](https://github.com/Jutho/TensorOperations.jl): Package Julia pour les contractions de tenseurs et les opérations associées.
- [VectorInterface.jl](https://github.com/Jutho/VectorInterface.jl): Interface Julia pour manipuler des objets de type vecteur.
- [TestParticle.jl](https://github.com/henry2004y/TestParticle.jl): Suivi de particules tests dans un champ électromagnétique avec Makie.
- [Kibisis.jl](https://github.com/Ha5hBr0wn/Kibisis.jl): Implémentation de listes doublement chaînées.
- [DynamicExpressions.jl](https://github.com/SymbolicML/DynamicExpressions.jl): Expressions dynamiques extrêmement rapides.
- [DistributedSparseGrids.jl](https://github.com/baxmittens/DistributedSparseGrids.jl): Implémentation Julia de grilles creuses hiérarchiques adaptatives.
- [WeightedPCA.jl](https://github.com/dahong67/WeightedPCA.jl): Analyse en composantes principales à pondération optimale pour des échantillons de qualité hétérogène.
- [SpeedyWeather.jl](https://github.com/milankl/SpeedyWeather.jl): La petite sœur d'un grand modèle de prévision météorologique.
- [WorldDynamics.jl](https://github.com/worlddynamics/WorldDynamics.jl): Un outil libre écrit en Julia pour les modèles d'évaluation intégrée à l'échelle mondiale.
- [StatisticalGraphics.jl](https://github.com/sl-solution/StatisticalGraphics.jl): Visualisation de données en Julia avec la bibliothèque VEGA.
- [TransportProperties.jl](https://github.com/vinodjanardhanan/TransportProperties.jl): Package Julia pour calculer les coefficients de diffusion, la conductivité thermique et la viscosité des gaz.
- [CLFFT.jl](https://github.com/JuliaGPU/CLFFT.jl): Interface Julia de la bibliothèque clFFT d'AMD.
- [GeometricTools.jl](https://github.com/byuflowlab/GeometricTools.jl): Méthodes de manipulation de données géométriques, de génération de maillages et de mise en forme pour la visualisation.
- [RedClust.jl](https://github.com/abhinavnatarajan/RedClust.jl): Package Julia pour le regroupement bayésien de données euclidiennes de grande dimension à partir de dissimilarités par paires.
- [GenericLinearAlgebra.jl](https://github.com/JuliaLinearAlgebra/GenericLinearAlgebra.jl): Une nouvelle approche de l'algèbre linéaire numérique en Julia.
- [EvoTrees.jl](https://github.com/Evovest/EvoTrees.jl): Implémentation Julia d'arbres boostés, compatible avec les CPU et les GPU.
