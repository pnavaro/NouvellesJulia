## Packages

- [BestModelSubset.jl](https://github.com/waitasecant/BestModelSubset.jl) : paquet Julia pour implémenter des algorithmes de sélection de modèles de régression de base.
- [CodeAI.jl](https://github.com/GenieFramework/CodeAI.jl) : Générateur de code par IA fondé sur OpenAI.
- [ConcurrentUtilities.jl](https://github.com/JuliaServices/ConcurrentUtilities.jl) : Utilitaires pour les traitements multithreads ou distribués en Julia.
- [EasyVega.jl](https://github.com/fredo-dedup/EasyVega.jl) : Liaisons Julia pour la grammaire de visualisation Vega.
- [EvoLP.jl](https://github.com/ntnu-ai-lab/EvoLP.jl) : Terrain d'expérimentation pour le calcul évolutionnaire en Julia.
- [HeatTransferFluids.jl](https://github.com/rydyb/HeatTransferFluids.jl) : Paquet Julia pour l'ingénierie des transferts thermiques avec des fluides.
- [HypergeometricFunctions.jl](https://github.com/JuliaMath/HypergeometricFunctions.jl) : Implémentation de fonctions hypergéométriques généralisées en Julia.
- [JefimenkoModels.jl](https://github.com/mikeingold/JefimenkoModels.jl) : Solveur temporel des champs électromagnétiques produits par des charges (électriques et magnétiques) et des courants arbitraires.
- [McmcHermes.jl](https://github.com/stevenalfonso/McmcHermes.jl) : Paquet pour exécuter des algorithmes de Monte-Carlo par chaînes de Markov.
- [NarmViz.jl](https://github.com/firefly-cpp/NarmViz.jl): Visualiser des règles d'association numériques pour les séries temporelles.
- [NonlinearSystems.jl](https://github.com/junyuan-chen/NonlinearSystems.jl) : Résoudre des systèmes d'équations non linéaires et des problèmes de moindres carrés non linéaires en Julia.
- [ParticleDA.jl](https://github.com/Team-RADDISH/ParticleDA.jl) :  Assimilation de données par filtre particulaire distribué avec MPI.
- [PrecompileTools.jl](https://github.com/JuliaLang/PrecompileTools.jl) : Réduire le temps avant la première exécution du code Julia.
- [ProjectEuler.jl](https://github.com/udohjeremiah/ProjectEuler.jl): Paquet permettant d'accéder hors ligne, depuis le REPL de Julia, aux problèmes mathématiques stimulants de Project Euler. C'est une ressource utile pour améliorer ses compétences en programmation Julia tout en résolvant des problèmes intéressants.
- [ReinforcementLearning.jl](https://github.com/JuliaReinforcementLearning/ReinforcementLearning.jl) : Paquet d'apprentissage par renforcement pour Julia.
- [ReTestItems.jl](https://github.com/JuliaTesting/ReTestItems.jl) : Exécuter des éléments de test en parallèle.
- [RTMsim.jl](https://github.com/obertscheiderfhwn/RTMsim) : Module Julia pour les simulations de remplissage par moulage par transfert de résine.
- [SimpleCrystals.jl](https://github.com/ejmeitz/SimpleCrystals.jl) : Interface de génération de structures cristallines simples pour les simulations de dynamique moléculaire.
- [SingularIntegrals.jl](https://github.com/JuliaApproximation/SingularIntegrals.jl) : Paquet Julia pour le calcul d'intégrales singulières.
- [SparsePCA.jl](https://github.com/Deepmalya3D/SparsePCA.jl) : Paquet Julia qui implémente l'algorithme d'analyse en composantes principales parcimonieuse (SparsePCA).
- [SpeciesDistributionToolkit.jl](https://github.com/PoisotLab/SpeciesDistributionToolkit.jl) : Étudier les distributions d'espèces en Julia.
- [TimeseriesTools.jl](https://github.com/brendanjohnharris/TimeseriesTools.jl) : Paquet pratique pour manipuler des séries temporelles en tant que séries mathématiques plutôt que comme structures de données indexées par date.
- [UnitfulCoordinateSystems.jl](https://github.com/mikeingold/UnitfulCoordinateSystems.jl) : Implémentation simple et efficace de systèmes de coordonnées physiques avec des dimensions Unitful.
