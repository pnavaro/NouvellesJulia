## Packages

- [Latte.jl](https://lattejl.org/dev/) probabilistic programming framework for latent Gaussian models.
- [AdditionalDistributions.jl](https://github.com/Santymax98/AdditionalDistributions.jl) ecosystem with additional univariate and multivariate probability distributions.
- [MinimalWorkingExamples.jl](https://github.com/BjarkeHautop/MinimalWorkingExamples.jl) run and share minimal working examples
- [PackedStructs.jl](https://github.com/JuliaData/PackedStructs.jl)
- [JuliaFormatter.jl](https://github.com/JuliaEditorSupport/JuliaFormatter.jl) update of the code formatter for Julia. 
- [TextMeasure.jl](https://github.com/jowch/TextMeasure.jl) backend-agnostic text layout engine (useful to avoid overlapping with plot annotations)
- [TeXLayout.jl](TeXLayout.jl) LaTeX typesetting package that is focused on rendering nice mathematics in Makie.jl 
- [TruncatedDistributions.jl](https://github.com/Distribution-Matching/TruncatedDistributions.jl) Support for univariate and multivariate truncated distributions.
- [Browzarr.jl](https://github.com/EarthyScience/Browzarr.jl) browser-based visualization framework for exploring and analyzing Zarr and NetCDF datasets.
- [Optim.jl](https://julianlsolvers.github.io/Optim.jl/) Update of the Univariate and multivariate optimization package.
- [DistributionsFactories.jl](https://github.com/Distribution-Matching/DistributionsFactories.jl) probability distributions parametarised by moments (mean, variance, etc.), and other measures (median, constrained domains, etc.).
- [AtmosphericTurbulenceSimulator.jl](https://github.com/aryavorskiy/AtmosphericTurbulenceSimulator.jl) A simple toolchain for simulating atmospheric speckles.
- [PureUMFPACK.jl](https://github.com/SciML/PureUMFPACK.jl) Pure-Julia sparse LU (UMFPACK translation).
- [SlicedWasserstein.jl](https://github.com/gianlucacovini/SlicedWasserstein.jl) Implementation of Sliced Wasserstein distance, SW barycenters and application to K-means clustering.
- [KitAMR.jl](https://github.com/CFDML/KitAMR.jl) massively parallel distributed computational fluid dynamics facility with adaptive mesh refinement.
- [LibPARI.jl](https://github.com/s-celles/LibPARI.jl) unofficial Julia interface to PARI/GP.
