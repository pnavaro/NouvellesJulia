## Packages

- [AgriDatasets.jl](https://github.com/lightbluetitan/AgriDatasets.jl)  AgriDatasets.jl is an open-science Julia package providing a curated collection of 71 agricultural, agronomic, soil, forestry, and animal science datasets, ready to use as DataFrame objects.
- [Apollonius.jl](https://github.com/gxono/Apollonius.jl) A Julia toolkit for planar Euclidean geometry.
- [AOCLFFTZ.jl](https://github.com/aelobdog/AOCLFFTZ.jl) An AbstractFFTs compatible Julia package for AMD's AOCL FFTZ library.
- [AtmosphericTurbulenceSimulator.jl](https://github.com/aryavorskiy/AtmosphericTurbulenceSimulator.jl) A simple toolchain for simulating atmospheric speckles.
- [BiotSavartBCs.jl](https://github.com/WaterLily-jl/BiotSavartBCs.jl) External flow boundary conditions for WaterLily using fast multi-grid Biot-Savart integral approximations.
- [Canapes.jl](https://github.com/AbrJA/Canapes.jl) Collaborative Algorithms & Non-negative Approximations for Prediction & Embeddings (Sparse).
- [HMatrixGPU.jl](https://github.com/MagneticSimulation/HMatrixGPU.jl) Hierarchical-matrix (𝓗-matrix) compression.
- [Quadriceps.jl](https://github.com/NittanyLion/Quadriceps.jl) Positive-weight cubature rules for the Gaussian weight and the cube
- [QuartzHDL.jl](https://github.com/org-arl/QuartzHDL.jl) Write FPGA logic in Julia, run it in Julia, compile it to Verilog.
- [Lenticulum.jl](https://github.com/MathStruct/Lenticulum.jl) An Implicit Learning Library.
- [MaterialDocs.jl](https://github.com/mthelm85/MaterialDocs.jl) A Documenter.jl writer plugin that generates Material Design 3 documentation sites .
- [MatrixFreeOperators.jl](https://github.com/RallypointOne/MatrixFreeOperators.jl) Matrix-free linear and nonlinear operators for solving PDEs on structured grids.
- [MultiprecisionExponential.jl](https://github.com/M4rinz/MultiprecisionExponential.jl) An arbitrary precision scaling and squaring algorithm for the exponential of a matrix.
- [NSDERungeKutta.jl](https://github.com/giancarloantonucci/NSDERungeKutta.jl) Runge-Kutta methods.
- [ScientificFitting.jl](https://github.com/Amin-El-Sayed/ScientificFitting.jl) Scientific fitting for Julia with explicit uncertainties, diagnostics, profiles, and Makie plots.
- [StaticStrings.jl](https://github.com/JuliaStrings/StaticStrings.jl) Fixed-length strings in Julia represented by NTuples.
- [TreeAMR.jl](https://github.com/eschnett/TreeAMR.jl) Tree-based octant-style AMR discretization.
- [VkFFT.jl](https://github.com/PaulVirally/VkFFT.jl) GPU FFT library.
