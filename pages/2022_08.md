## Packages

- [PProf.jl](https://github.com/JuliaPerf/PProf.jl) : Export des profils Julia au format pprof.
- [MeshPlots.jl](https://github.com/JuliaGeometry/MeshPlots.jl): Recettes Plots.jl pour Meshes.jl.
- [SpeedyWeather.jl](https://github.com/milankl/SpeedyWeather.jl): La petite sœur d'un grand modèle de prévision météorologique.
- [Hydro.jl](https://github.com/chongchonghe/Hydro.jl): Un code hydrodynamique modulaire écrit en Julia pur.
- [IncompressibleNavierStokes.jl](https://github.com/agdestein/IncompressibleNavierStokes.jl): Solveur de Navier-Stokes incompressible.
- [HOHQMesh.jl](https://github.com/trixi-framework/HOHQMesh.jl): Interface Julia du générateur de maillages HOHQMesh, qui produit des maillages quadrilatéraux et hexaédriques courbes pour les simulations numériques d'ordre élevé.
- [SnoopCompile.jl](https://github.com/timholy/SnoopCompile.jl): Accélération des packages par une précompilation plus étendue.
- [StableTrees.jl](https://github.com/rikhuijzer/StableTrees.jl): Apprentissage automatique explicable par extraction de règles.
- [AlgebraicSolving.jl](https://github.com/algebraic-solving/AlgebraicSolving.jl): Package Julia pour la résolution algébrique de systèmes polynomiaux multivariés.
- [CovarianceFunctions.jl](https://github.com/SebastianAment/CovarianceFunctions.jl): Opérations paresseuses, structurées et efficaces sur les matrices de noyau.
- [LocalPoly.jl](https://github.com/jbshannon/LocalPoly.jl): Régression polynomiale locale en Julia pur.
- [EndoBeams.jl](https://gitlab.emse.fr/pierrat/EndoBeams.jl): Package Julia d'éléments finis pour les problèmes de contact entre poutre et surface.
- [SaveREPL.jl](https://github.com/carstenbauer/SaveREPL.jl): Package pour enregistrer les commandes du REPL dans un fichier de script.
- [KernelAbstractions.jl](https://github.com/JuliaGPU/KernelAbstractions.jl): Package permettant d'écrire des noyaux de type GPU ciblant différentes plateformes d'exécution.

Les 3 derniers packages sont un ensemble qui regroupe des techniques numériques classiques pour résoudre des EDP. L'objectif
est de pouvoir les utiliser facilement avec de l'apprentissage statistique et explorer ces nouvelles méthodes sans passer trop de temps
sur la partie analyse. 

- [NodalPolynomialSpaces.jl](https://github.com/vpuri3/NodalPolynomialSpaces.jl): Solveurs spectraux d'EDP fondés sur les polynômes de Lagrange.
- [FourierSpaces.jl](https://github.com/vpuri3/FourierSpaces.jl): Méthodes spectrales de Fourier pour résoudre des équations aux dérivées partielles.
- [AbstractPDEInterfaces.jl](https://github.com/vpuri3/AbstractPDEInterfaces.jl): Écosystème pour écrire des solveurs d'équations aux dérivées partielles.
