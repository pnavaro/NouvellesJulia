# Octobre 2026

Bonjour,

La version [1.13.3](https://julialang.org/blog/2026/09/julia-1.13-highlights/) est sortie il y a quelques jours. Après deux années de stagnation Julia a repris sa progression dans le [TIOBE index](https://www.tiobe.com/tiobe-index/) qui mesure la popularité des langages. 

Julia est l'un des langages les sobres en crédits LLMs ([Which programming languages are most token-efficient?](https://martinalderson.com/posts/which-programming-languages-are-most-token-efficient/)). Il y a peut être un lien.

## Packages

- [AppleNeuralEngine.jl](https://github.com/pitsianis/AppleNeuralEngine.jl) Julia on the Apple Neural Engine.
- [BigHOPs.jl](https://github.com/dom-linkevicius/BigHOPs.jl) Hyperparameter optimization in Julia.
- [CubatureRules.jl](https://github.com/IlianPihlajamaa/CubatureRules.jl) Quadrature and cubature rules generated on demand at arbitrary order and arbitrary precision.
- [ElasticWaves.jl](https://github.com/JuliaWaveScattering/ElasticWaves.jl) calculate propagation and scattering of elastic waves.
- [GaussChebyshevFracture.jl](https://github.com/ajacquey/GaussChebyshevFracture.jl) A set of numerical methods (Gauss-Chebyshev quadrature) for coupled fracture problems.
- [HyperCloud.jl](https://github.com/blhackslash/HyperCloud.jl) A comprehensive meshfree simulation framework for solving N-dimensional hyperbolic PDEs with high-order numerical accuracy.
- [MapperStudio.jl](https://github.com/JuliaTDA/MapperStudio.jl) Local Mapper and topological data analysis workbench.
- [MultiObjectiveProblems.jl](https://github.com/VectorOptimizationGroup/MultiObjectiveProblems.jl) benchmark problems for multiobjective optimization, with analytic per-objective gradients, flexible catalog filtering, and a unified interface for testing and comparing solvers.
- [ODEParameterEstimation.jl](https://github.com/orebas/ODEParameterEstimation.jl) parameter Estimation for ODE models.
- [ThreadTeams.jl](https://github.com/vchuravy/ThreadTeams.jl) Persistent parked worker pool for low-overhead parallel loops.
