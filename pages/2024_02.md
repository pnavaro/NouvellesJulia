## Packages

- [ArnoldiMethod.jl](https://github.com/JuliaLinearAlgebra/ArnoldiMethod.jl) Méthode d'Arnoldi avec redémarrage de Krylov-Schur, entièrement en Julia.
- [DistributedSparseGrids.jl](https://github.com/baxmittens/DistributedSparseGrids.jl) Implémentation de grilles creuses adaptatives hiérarchiques.
- [DotEnv.jl](https://github.com/tecosaur/DotEnv.jl) Récupère les variables d'environnement depuis les fichiers `.env` de vos projets Julia.
- [ExplicitImports.jl](https://github.com/ericphanson/ExplicitImports.jl) Repère les exports implicites dont dépend un module Julia afin de les rendre explicites.
- [GALAHAD.jl](https://github.com/ralna/GALAHAD) Bibliothèque de modules Fortran modernes pour l'optimisation non linéaire, avec une interface Julia.
- [Handcalcs.jl](https://github.com/co1emi11er2/Handcalcs.jl) Paquet Julia qui convertit des calculs Julia en expressions LaTeX rendues.
- [PairPlots.jl](https://github.com/sefffal/PairPlots.jl) Visualisations élégantes et flexibles de données de grande dimension.
- [PartitionedArrays.jl](https://github.com/fverdugo/PartitionedArrays.jl) Vecteurs et matrices creuses partitionnés pour les calculs parallèles à mémoire distribuée.
- [ProgressTMap.jl](https://github.com/OliverDudgeon/ProgressTMap.jl) Fonction `map` multithreadée en Julia avec barre de progression.
- [NeuroTreeModels.jl](https://github.com/Evovest/NeuroTreeModels.jl) Modèles arborescents différentiables pour les données tabulaires.
- [RayTraceHeatTransfer.jl](https://github.com/NikoBiele/RayTraceHeatTransfer.jl) Effectue des calculs de transfert thermique radiatif dans une enceinte définie par l'utilisateur, avec un milieu participant ; le lancer de rayons Monte-Carlo permet d'obtenir des facteurs d'échange et d'accélérer ces calculs.
- [TestReadme.jl](https://github.com/thchr/TestReadme.jl) Teste automatiquement le contenu exécutable d'un fichier README de projet Julia.
- [TopologicalNumbers.jl](https://github.com/KskAdch/TopologicalNumbers.jl) Paquet Julia pour calculer des nombres topologiques.
- [VkFFTCUDA.jl](https://github.com/PaulVirally/VkFFTCUDA.jl) Liaisons Julia pour VkFFT.
